## Technical Specifications

1. **Formats**: PNG (`image/png`), fully compatible with all modern browsers and Next.js Image optimization pipeline.
2. **Aspect Ratios**:
   - `[slug].png`: Strictly 2:3 vertical aspect ratio ($600 \times 900\text{ px}$).
   - `[slug]_banner.png`: Strictly 16:9 widescreen cinematic aspect ratio ($1920 \times 1080\text{ px}$).
3. **No Baked-in Typography**:
   - Images do not contain embedded titles, credits, dates, logos, or marketing badges.
   - All text is rendered using semantic, accessible, scalable HTML elements styled with Tailwind CSS to ensure complete legibility and compliance with WCAG 2.2 AA standards.
4. **Color Scrim & Contrast Protection**:
   - Backdrops are overlaid with progressive dark gradients (`from-[#0B0914] via-[#0B0914]/85 to-transparent`) in hero sections, guaranteeing that overlaid white text maintains a minimum contrast ratio of $> 7:1$ (exceeding WCAG AAA).
